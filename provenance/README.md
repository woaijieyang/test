# Provenance and evidence limits

This directory preserves the analysis that informed final-best-v1 and the earlier user-provided analysis. The package starts from the v1.3 static patch's source prompt lineage and incorporates the comprehensive R2R/RxR audit in `FINAL_REVIEW_ANALYSIS.md`. The prompt text in `粘贴的文本 (1).txt` was treated as an additional proposal, not copied verbatim, because its runtime statement (“one sub-instruction at a time”) conflicts with the comprehensive analysis and the current experiment contract (all stages supplied together).

The 1,839 R2R and 1,223 RxR figures describe the uploaded evaluation files only. Historical run metrics are included in the report as historical evidence. No final-best-v1 model call, navigation replay, token capture or held-out test was performed when assembling this package.
