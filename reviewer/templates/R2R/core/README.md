# R2R Reviewer Fixed Core

The ten files in this directory are the unconditional, independent Reviewer teaching Core for R2R English. They load in R01–R10 order on R0 and R1. Each case has its own source, candidate, evidence map, review output and provenance. The verdict is local to that teaching example and is never a vote for the current task.

| Slot | Template | Primary review boundary | Expected teaching verdict |
|---|---|---|---|
| R01 | R2R-CORE-R01 | Hard PASS: surface paraphrase, expected observation and correct far-wall doorway target | PASS |
| R02 | R2R-CORE-R02 | Wrong ordinal doorway identity and terminal placement | REVISE |
| R03 | R2R-CORE-R03 | Hard PASS: coupled movement without false boundary | PASS |
| R04 | R2R-CORE-R04 | Orientation-only micro-stage / over-segmentation | REVISE |
| R05 | R2R-CORE-R05 | Hard PASS: terminal ordinal position remains attached to final objective | PASS |
| R06 | R2R-CORE-R06 | Multiple completed objectives buried in one stage | REVISE |
| R07 | R2R-CORE-R07 | Premature handoff assumes hallway entry that was omitted | REVISE |
| R08 | R2R-CORE-R08 | Expected observation incorrectly promoted to destination | REVISE |
| R09 | R2R-CORE-R09 | Hard PASS: temporal trigger remains attached to bench-relative terminal placement | PASS |
| R10 | R2R-CORE-R10 | Source-level route-critical exit ambiguity; no candidate is authored | UNRESOLVED |

These are curated teaching demonstrations, not official human review annotations or navigation ground truth. Candidate corruption is explicitly marked per case; a source-abstention example with no Candidate is not a corrupted Candidate. Evidence must be grounded in the exact Source and the exact Candidate stage. The Dynamic Paired and Diagnostics libraries are separate from this unconditional Core.
