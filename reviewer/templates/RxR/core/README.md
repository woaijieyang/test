# RxR Reviewer fixed core — 10 cases

These are the v5-format migrations of the ten original v1 Reviewer teaching cases. They are independent review demonstrations, not copies of Generator outputs. The JSON files in this directory are the runtime fixed core; the matching `legacy/` files remain archival provenance copies and are excluded from dynamic retrieval. Each core review is paired by `pair_id` with the corresponding Generator core template ID.

|Slot | File | Original review teaching purpose |
|---|---|---|
| R01 | `G01_RxR-CORE-R01.json` | PASS for coherent stages and a supported exit-to-entry handoff |
| R02 | `G02_RxR-CORE-R02.json` | REVISE when an until endpoint is detached from its continuing movement |
| R03 | `G03_RxR-CORE-R03.json` | REVISE for an invented physical stop at a threshold |
| R04 | `G04_RxR-CORE-R04.json` | REVISE when target-identifying information arrives after selection |
| R05 | `G05_RxR-CORE-R05.json` | REVISE when textual mention order reverses execution order |
| R06 | `G06_RxR-CORE-R06.json` | REVISE when a superseded correction is executed as an extra action |
| R07 | `G07_RxR-CORE-R07.json` | REVISE when an endpoint match erases required route history and return |
| R08 | `G08_RxR-CORE-R08.json` | UNRESOLVED for genuine source-level reference/direction ambiguity |
| R09 | `G09_RxR-CORE-R09.json` | REVISE an over-rejection caused by missing imagery when text is executable |
| R10 | `G10_RxR-CORE-R10.json` | PASS for an alternative valid cut with bounded orientation |

The core is injected in R01–R10 order on every RxR en-US Reviewer call (R0 and R1). It is independent from the paired dynamic Reviewer cases. Dynamic retrieval adds 2–4 Reviewer cases paired to the Generator's dynamic IDs, then 0–2 relevant Diagnostics.
