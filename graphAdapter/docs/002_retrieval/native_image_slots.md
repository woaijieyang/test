# AwareVLN 原生图像槽与 002 读取接口

宿主以 `model.config.num_video_frames` 为总预算 B。已核验 checkpoint 的 B=8。输入的原顺序是前 7 个历史槽和末位当前 RGB。历史来自所有 primitive 端点的均匀采样，包含当前在内的实际观察数短于 B 时原 sampler 在前端补黑帧。每次 REASON 可以重用同一观察，决策编号独立递增。

002 固定当前帧与原图总预算。原技术文档的图证据包模式在 B=8 时保留当前 1 槽、近期 3 槽，其余 4 槽供全局历史。另设小样本单槽诊断，先取得原 8 槽，再替换最多 1 个历史槽。单槽诊断用于测量较小的视觉分布变化。替换后按实际采集时间排序。图像是封存的正常 RGB 经原 host-view 变换的结果；检索向量用于排序，文本证据经原 question/tokenizer 通道进入模型，图像编号依最终排序确定。

原始图像选择仍调用宿主 `sample_and_pad_images`。GraphAdapter 用 `interfaces/host_slots.py` 复现它的槽位编号；材料化前后核对原图、帧身份、最终 tensor 和占位 token。`MemoryMaterialized` 新增 native_slots、selected、replaced_slots、checkpoint_budget。完整调用以 request_id、decision_id、call_id 串联。失败或证据不足时使用原宿主所有图像及问题。训练模型的 B=8；B 的其他值只用于验证接口适配，不能据此推断模型在其他帧数上的效果。

RxR-US 10035 第14次调用的实际结果：原生步号 0/4/9/14/18/23/28/33，单槽诊断为 0/4/9/16/18/23/28/33。独立比较宿主 PNG，差异只有第4槽。实际图片占位8个；投影输出[8,196,4096]；两边均右转15度。完整轨迹均61步成功。该样本证明了图像预算内消费和行为保持，导航增益需另验。

验证发现通用 selector 的空余槽补足分支曾以 n 代替 n−1 计算原时间采样偏好，已统一为原宿主索引。受影响范围是多图图包的补位分支，单槽历史结果不受此差异影响。34项相关检查通过，覆盖 B=1/2/4/8/12 和最长501帧，与原 sampler 输出像素逐槽比较。
