# 正式导航结果报告模板（非实验结果）

此文件规定生成报告的结构，不包含实验数据，不得作为已完成结果登记。正式报告由已验收机器记录生成。

## 身份与范围

| 字段 | 要求 |
|---|---|
| record_id / run_id | 唯一、不可复用 |
| 实际完成与核验时间 | 记录时区，展示采用 Asia/Singapore |
| claim_scope | 正式导航或准确的诊断类别 |
| dataset / split / language | R2R 与 RxR-US 分开 |
| 覆盖 | 计划、完成、普通失败、异常、缺失与重复 |
| 模型 | checkpoint 身份、完整文件树哈希 |
| 源码与环境 | 实际代码摘要、上游版本、运行环境身份 |
| 配置与网格 | 启动配置、实际配置集合、profile 及哈希 |
| 原始证据 | manifest、逐任务记录、轨迹、独立复算及验收回执 |

## 有限值与完整性

分别列出 SPL、NE、nDTW 的 valid/nonfinite 数量、缺失/重复、普通导航失败和基础设施异常。说明独立复算的方法、差异与证据哈希。不能通过丢弃 33 条异常或其他失败样本制造完整成绩。

## 协议、过程与限制

说明网格修复及与旧协议的可比性；解释普通失败、重试和修订情况。原始响应、图像和轨迹保留在运行目录。阶段 conclusion 负责记录全过程，本报告不复制原始大文件。smoke、mock、部分或失败运行不进入正式总表。
