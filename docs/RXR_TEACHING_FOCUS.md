## Recommendation disposition

Adopt: frozen baseline; case-specific Core lessons; event-local Core coverage; minimum supported wording for 002/020; paired and dependent-artifact rebuilding; inspection of actual projections; unchanged diagnostics that already demonstrate real defects; same-schema regression and R2R isolation.

Refine: no universal ban on whole-stage evidence, no automatic strengthening of expected states, no rule that every route mentioning a landmark must stop there, and no broad change to lesson precedence when explicit case fields solve the demonstrated problem.

Defer: new source cases, retrieval/IDF changes, universal expanded cards, automatic token-based example dropping and new navigation efficacy claims. These are separate experimental variables, not necessary fixes for the verified teaching gaps.
