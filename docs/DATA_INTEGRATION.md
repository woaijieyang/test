# 数据链接、运行保护与派生网格

## 输入来源与链接映射

| 工作目录入口 | 实际全局来源 | 用途 |
|---|---|---|
| `data/datasets/R2R_VLNCE_v1-3_preprocessed` | `/data/zy/vln/data/raw_data/eval_annotations/R2R_VLNCE_v1-3_preprocessed` | R2R 原始标注与 GT |
| `data/datasets/RxR_VLNCE_v0` | `/data/zy/vln/data/raw_data/eval_annotations/rxr_vlnce_v0` | RxR 标注、guide/follower GT |
| `data/scene_datasets/mp3d` | `/data/zy/vln/data/raw_data/scenes/mp3d` | 原始 GLB 与原网格 |
| `models/awarevln` | `/data/zy/vln/model/upstream/awarevln` | 已存在的官方权重及 tokenizer |
| `data/derived/navmeshes/<profile_id>` | case1 自有目录 | 派生网格与构建清单 |

数据入口通过 `data/.shared-ro/raw_data` 间接链接全局原始数据；模型入口通过 `models/.shared-ro/awarevln` 指向官方权重。原始资产不复制、不移动、不覆盖。已核对这些全局入口的真实路径未指向其他 case。

`scripts/setup_data_links.py` 先检查全部既有入口和父路径，再建立链接。正确链接可重复执行；错误链接、同名实体和父目录链接逃逸会报错，不覆盖它们。文件缺失不会被其他 case、backup 或小样本数据静默替代。

## 为什么仅有链接还不够

普通 shell 中存在链接只代表路径可达，不能证明数据受保护。模型、模拟器与数据检查必须通过 `scripts/with_runtime.sh`。

启动器优先探测独立 mount namespace，只读 bind mount 成功时建立内核只读视图。不可用时使用 Landlock 写入白名单；两者均不能满足要求时退出。子进程继承保护。当前主机已在独立测试目录验证 Landlock ABI 4 的读写边界，正式部署还需对应代码身份的检查回执。

| 模式 | 允许的额外写入 | 使用场景 |
|---|---|---|
| 默认 runtime | runtime、缓存、outputs、logs、data/derived、configs/local | 数据审计、模拟器、模型、导航及指标审计 |
| `--prepare-configs` | configs/locks、configs/diagnostics | 冻结环境和预先指定诊断任务 |
| `--results-write` | docs/results | 正式结果登记与生成 |
| 独立 build 启动器 | 新环境、构建缓存、upstream、src 元数据、依赖锁等自有构建目录 | 安装依赖；禁止写 backup 和全局资产，GPU 不可见 |

真实导航入口拒绝两个管理模式。保护负向测试只在自有夹具中尝试写入，不对共享数据执行试写。输出路径也需要解析检查，不能通过链接把输出导向共享资产。

## 数据身份与冻结

R2R 正式清单为 val_unseen 1,839 条；RxR 为 guide/en-US val_unseen 1,223 条。核验不仅比较数量，还检查每个 scene、episode、instruction 身份及 GT。RxR 原生 NDTW 会读取 guide 和 follower 两份 GT，因此两份文件均纳入冻结身份；本次已读取的源文件键无重叠。

## 官方依据与最终候选选择

已检索[Recast rcConfig官方说明](https://recastnav.com/structrcConfig.html)：水平和垂直体素会影响使用体素单位的参数；减小垂直体素可改善台阶/高度不连续处的连接，机器人半径通过可走区域侵蚀保持碰撞余量。此次保留radius=.1、height=1.5，未关闭高度/障碍过滤。

[Recast BuildSettings](https://recastnav.com/structBuildSettings.html)明确regionMinSize/regionMergeSize采用体素单位。结合[冻结Habitat-Sim源码](https://github.com/facebookresearch/habitat-sim/blob/856d4b08c1a2632626bf0d205bf46471a99502b7/src/esp/nav/PathFinder.cpp)，实际minRegionArea/mergeRegionArea取这些值的平方。故默认(20×.05)²=1m²；水平网格改.025时设40，保持(40×.025)²=1m²。未缩放阈值的候选产生8条密集GT断连；恢复面积阈值后全量3062端点与所有受检参考点距离均通过。该选择依据几何及完整回归，不依据SR。

同一PathFinder源码执行原生表面投影、moveAlongSurface及高度修正，因此“转向绝不发生垂直位置变化”并非此模拟器契约。保留名义位移筛查，另以同一profile原生独立动作回放逐步核对真实轨迹，并检查reset不变、有限值、无跨楼层跳跃。没有在模型或恢复逻辑中添加位置修补。

[AwareVLN冻结版NDTW实现](https://github.com/GWxuan/AwareVLN/blob/8f14eb8450cdd14ff4e3ba1ea04824255121e6be/evaluation/habitat_extensions/measures.py)使用密集GT位置与实际去重轨迹的欧氏DTW，因此派生首点修正需要明确绑定GT身份，不能仅更改起点却沿用未标明的旧GT。四条目标修正任务的GT末点本就不是目标，保持原轨迹不做强行对齐。

最终可重建配置为configs/navmesh-recipe.json；入口scripts/build_navmesh_profile.py逐个核对重建网格SHA与已验收候选一致。最终profile `awarevln-mesh025-region40-endpoint9-v1` 的全量静态验收：outputs/navmesh/final-static.json；48条真实运动及独立回放：outputs/motion-final-01/motion-audit.json和motion-replay.json。以上通过仍不代表正式模型全量完成。
