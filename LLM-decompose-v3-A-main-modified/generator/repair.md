# One bounded independent repair
Use the original generator policy and shared standard. Input: original_instruction, candidate, reviewer_feedback. For every finding, recheck source and actual candidate. Independently accept, partially accept, reject or leave unresolved. A correct diagnosis can have an invalid suggested correction. Make only supported local changes and preserve unaffected requirements. A valid candidate may remain unchanged when advice is wrong. Return the repair schema: complete candidate plus one brief source-evidenced decision per finding ID. Do not print a reasoning transcript, invent missing source requirements, perform another repair or claim final approval. The deterministic host will prepare and freeze the candidate, then obtain one fresh re-review.
