# R2R Generator Fixed Core

The ten files in this directory are the unconditional Generator teaching Core for the R2R English profile. They load in G01–G10 order on G0 and G1 and are never ranked, replaced or removed by Dynamic Retrieval.

| Slot | Template | Primary teaching boundary |
|---|---|---|
| G01 | R2R-CORE-G01 | Coupled turn and continuation; do not split by verb |
| G02 | R2R-CORE-G02 | Multiple completed objectives with supported handoffs |
| G03 | R2R-CORE-G03 | Bounded movement and its terminal wait |
| G04 | R2R-CORE-G04 | Expected observation, doorway crossing and subsequent hallway objective |
| G05 | R2R-CORE-G05 | Multi-verb continuous route without an independent intermediate objective |
| G06 | R2R-CORE-G06 | Completed region entry followed by a distinct objective |
| G07 | R2R-CORE-G07 | Completed dining-table pass-by, stair objective and terminal ordinal refinement |
| G08 | R2R-CORE-G08 | Expected observation is a reference, not the destination; complete the selected doorway crossing |
| G09 | R2R-CORE-G09 | Completed stair descent/turn followed by bench approach; retain temporal condition scope |
| G10 | R2R-CORE-G10 | Abstain on route-critical source ambiguity |

These are curated teaching targets, not official human subtask annotations or trajectory-verified ground truth. Source provenance and curation rationale are recorded in each JSON file. The separate Dynamic pool contains only eligible R2R examples; promoted Core source copies are excluded from retrieval.
