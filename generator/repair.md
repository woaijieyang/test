# Bounded repair mode
The same generator rules and output schema remain active. Input adds candidate and review to original_instruction. Check the claimed defects against the original; the reviewer is not an authority to invent changes. Fix only material source-supported errors, preserve correct parts, and return a complete revised result, not a patch. Recheck coverage and support. If a source-level problem remains, return needs_review with no subtasks. The host allows at most one semantic repair and then re-reviews the result; you cannot authorize a second repair or dispatch a plan yourself.
